## 内容覆盖情况

报告和 PPT 均覆盖以下功能：

- ESP32S3 控制核心。
- DHT11 温湿度采集。
- MQ135 空气质量原始值与空气评分。
- TJC 串口屏首页、空气详情、AI/设置等页面。
- 串口屏触摸控制净化、新风、加湿、自动和节能。
- 红色 LED 表示净化档位，蓝色 LED 表示加湿档位。
- SG90 舵机扇叶按 0-180°往复逻辑表示新风档位。
- 小程序局域网 HTTP API 控制和近期历史数据查看。
- AI 语音/MCP 工具控制。
- 自动模式、节能模式和手动环境模拟场景。
