# bread-compact-wifi 代码连线表

本文档依据当前固件代码生成，适用于 `bread-compact-wifi` 板型。GPIO 定义以
[`config.h`](../xiaozhi-esp32/main/boards/bread-compact-wifi/config.h) 为准；当前代码已启用 `AUDIO_I2S_METHOD_SIMPLEX`。

## 1. 接线前注意事项

1. 所有外设必须与 ESP32-S3 共地。
2. ESP32-S3 GPIO 只能承受 3.3V 逻辑电平，GPIO1、GPIO2 等 ADC 输入不得超过 3.3V。
3. LD2450、串口屏、功放和舵机等 5V 负载应使用稳定的 5V 电源，不得由 GPIO 供电。
4. UART 必须交叉连接：外设 TX 接 ESP32 RX，外设 RX 接 ESP32 TX。
5. GPIO13、GPIO14 只能直接驱动带限流电阻的小功率指示 LED。继电器、灯带、电机等负载必须增加三极管、MOSFET 或驱动模块。
6. 当前没有为独立照明灯分配 GPIO；GPIO48 是板载状态灯，不应作为正式照明输出。

## 3. 模块逐项连线表

### 3.1 HLK-LD2450 雷达

| LD2450 | ESP32-S3/电源 | 说明 |
| --- | --- | --- |
| `VCC` | 稳定 `5V` | 不从 GPIO 取电 |
| `GND` | `GND` | 必须共地 |
| `TX` | `GPIO11` | 雷达发送，ESP32 UART1 接收 |
| `RX` | `GPIO12` | ESP32 UART1 发送，雷达接收 |

串口参数：`256000 baud`、`8N1`、无流控。正常目标帧以 `AA FF 03 00` 开头、以
`55 CC` 结尾。使用 USB 转串口工具调试时，不要让转接板 TX 和 ESP32 GPIO12 同时驱动
LD2450 RX。

### 3.2 TJC 串口屏

| TJC 串口屏 | ESP32-S3/电源 | 说明 |
| --- | --- | --- |
| `VCC` | 按屏幕规格接电，当前硬件通常使用稳定 `5V` | 不从 GPIO 取电 |
| `GND` | `GND` | 必须共地 |
| `RX` | `GPIO41` | 接 ESP32 UART2 TX |
| `TX` | `GPIO42` | 接 ESP32 UART2 RX |

串口波特率为 `9600`。GPIO41、GPIO42 已被屏幕占用，不得同时连接 OLED。

### 3.3 DHT11 温湿度传感器

| DHT11 | ESP32-S3/电源 | 说明 |
| --- | --- | --- |
| `VCC` | `3.3V` | 与 GPIO 电平一致 |
| `GND` | `GND` | 必须共地 |
| `DATA` | `GPIO18` | 建议 DATA 与 3.3V 之间增加 4.7kΩ～10kΩ 上拉电阻 |

### 3.4 MQ135 空气质量模块

| MQ135 | ESP32-S3/电源 | 说明 |
| --- | --- | --- |
| `VCC` | 按模块规格供电，常见模块为 `5V` | 加热器耗电较大，使用稳定电源 |
| `GND` | `GND` | 必须共地 |
| `AO` | `GPIO1 / ADC1_CH0` | 接入前实测 AO，必须保证不超过 3.3V；必要时增加分压 |
| `DO` | 不连接 | 当前代码未使用数字输出 |

### 3.5 GL5528 光敏模块

| 光敏模块 | ESP32-S3/电源 | 说明 |
| --- | --- | --- |
| `VCC` | `3.3V` | 禁止使用会让 AO 超过 3.3V 的供电方式 |
| `GND` | `GND` | 必须共地 |

| `DO` | 不连接 | 当前代码未使用数字输出 |

### 3.7 MAX98357A I²S 功放与扬声器

| MAX98357A | ESP32-S3/电源 | 说明 |

### 3.8 智能家居执行器

| 执行器 | 信号连接 | 电源连接 | 说明 |
| --- | --- | --- | --- |
| 净化器红色指示 LED | `GPIO13 → 限流电阻 → LED正极`，LED负极接 GND | GPIO 信号供电 | 只适用于小功率指示 LED |
| 加湿器蓝色指示 LED | `GPIO14 → 限流电阻 → LED正极`，LED负极接 GND | GPIO 信号供电 | 只适用于小功率指示 LED |
| 0–180°位置舵机扇叶 | 信号线接 `GPIO21` | 红线接外部稳定 5V，棕/黑线接公共 GND | 禁止由 GPIO 或 3.3V 引脚给舵机供电 |

舵机当前档位参数：

| 档位 | 往复角度范围 | 每步角度 | 步进间隔 |
| ---: | ---: | ---: | ---: |
| `0` | 固定 `0°` | — | — |
| `1` | `20°–70°` | `2°` | `90ms` |
| `2` | `10°–120°` | `3°` | `60ms` |
| `3` | `0°–180°` | `4°` | `40ms` |

舵机角度 `0°–180°` 线性映射为 `500–2500µs` 脉宽，周期为 `20ms`。当前档位表达的是
扇叶往复范围和速度，不是连续旋转舵机的转速档位。

### 3.9 外接按键

| 按键 | ESP32-S3 | 另一端 | 固件动作 |
| --- | --- | --- | --- |
| BOOT | `GPIO0` | `GND` | 配网或聊天控制；启动时按住可能进入下载模式 |
| 触摸/说话 | `GPIO47` | `GND` | 按下开始监听，松开停止监听 |
| 音量加 | `GPIO40` | `GND` | 单击加音量，长按最大音量 |

这些按键在代码中均使用默认的低电平有效配置和内部上拉。

## 4. 推荐公共供电结构

```text
稳定 5V ──┬── ESP32-S3 开发板 5V/VIN
          ├── LD2450 VCC
          ├── TJC 串口屏 VCC（以屏幕规格为准）
          ├── MAX98357A VIN（以模块规格为准）
          └── 0–180°位置舵机 VCC

ESP32 3.3V ──┬── DHT11 VCC
             ├── GL5528 VCC
             └── INMP441 VCC

所有模块 GND ───────── ESP32-S3 GND
```

MQ135 应按模块规格单独确认供电电压；无论模块使用 5V 还是 3.3V，其 AO 接入 GPIO1
前都必须确保电压不超过 3.3V。雷达、屏幕、功放和舵机同时工作时，应为 5V 电源留出足够
电流余量；出现 ESP32 重启或 `Brownout detector was triggered` 时，应优先检查供电压降和
共地连接。

## 5. 上电前核对清单

- [ ] 所有外设与 ESP32-S3 共地。
- [ ] LD2450 TX 接 GPIO11，LD2450 RX 接 GPIO12，没有接反。
- [ ] TJC RX 接 GPIO41，TJC TX 接 GPIO42，没有接反。
- [ ] MQ135 AO 和光敏 AO 实测不超过 3.3V。
- [ ] INMP441 使用 3.3V 供电。
- [ ] GPIO13、GPIO14 外接 LED 已串联限流电阻。
- [ ] 舵机使用外部稳定 5V，信号线接 GPIO21。
- [ ] 扬声器只接 MAX98357A 的 SPK+、SPK-。
- [ ] 没有两个发送端同时连接并驱动同一个 UART RX。
- [ ] GPIO41、GPIO42 没有再连接 OLED。
