# 2026-07-28 小程序主看板与操作后台拆分交付

## 目标

将面向住户的日常家居功能与面向开发、答辩和调试的功能分离，避免主页面被连接参数、手动数据、日志和诊断信息占满。

## 页面职责

### 家居主看板

`mini_program_demo/pages/index/index.*` 只保留：

- 环境状态、舒适度和建议。
- 一键家居场景。
- 自动/节能模式和设备控制。
- 照明开关。
- 雷达位置和环境趋势。
- 当前告警。

后台入口位于页面最底部，以灰色小字“设备配置、调试与操作后台”显示。

### 操作后台

`mini_program_demo/pages/admin/admin.*` 集中提供：

- ESP32 地址、Token 和离线演示配置。
- 真实传感器系统/手动传感器系统切换。
- 手动数值和环境预设。
- 自动化规则。
- 告警与操作日志。
- 固件和传感器诊断。

## 共享服务

新增 `mini_program_demo/utils/smart_home_service.js`，统一管理：

- 局域网 HTTP 请求和 Token 请求头。
- 本地连接配置。
- 离线演示状态、历史、事件和控制行为。

两个页面不再各自维护独立的设备连接和模拟数据。

## 传感器双系统

后台通过 `/api/environment` 切换数据源：

```json
{"enabled": false}
```

表示读取真实硬件传感器；`enabled=true` 并携带温度、湿度、空气评分时，表示启用手动传感器系统。切换后主看板在 `onShow` 中自动重新读取状态。

## 验证

- 35 项 Python 回归测试通过。
- 主页面、后台页面和共享服务 JavaScript 语法检查通过。
- 小程序全部 JSON 可解析。
- 主页面和后台 WXML 结构及所有事件绑定检查通过。
- 本阶段未修改 ESP32 固件，沿用上一阶段已构建固件。

## 边界

- 后台入口是普通页面导航，不是账号权限系统。
- 真实产品发布前仍需增加用户身份、设备绑定和云端 HTTPS 服务。
- 手动传感器系统用于演示和测试，不代表真实环境。
