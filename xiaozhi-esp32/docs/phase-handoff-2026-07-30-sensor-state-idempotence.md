# 2026-07-30 传感器状态与幂等控制阶段交付

## 完成内容

- 控制器新增传感器样本防御性校验：温度、湿度必须是有限值且处于允许范围，MQ135 原始值必须处于 12 位 ADC 范围。
- 新增 `last_sensor_sample_`，真实传感器样本与 `manual_sample_` 分开保存。
- 手动环境模式开启期间仍持续接收并保存真实采样，但不覆盖当前手动演示画面。
- 关闭手动环境模式后立即恢复最近一次真实采样；没有真实采样时显示无有效数据，不再沿用手动数值。
- 手动环境数据不参与真实传感器突变告警，避免场景切换触发误告警。
- 设备、灯光、自动模式、节能模式和自动化规则 setter 增加幂等判断。
- 自动/节能策略仅在目标档位变化时重写 LED PWM 或舵机档位，降低重复日志和无效硬件操作。
- 模式和自动化规则只有实际变化时才写入 NVS。
