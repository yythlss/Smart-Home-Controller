# 2026-07-28 小程序演示增强阶段交付

## 目标

在不改动任何硬件的前提下，增加可独立演示的软件功能，并保持现有传感器、执行器、HMI、MCP 和 HTTP 功能兼容。

## 已完成

- 小程序新增离线演示开关，无 ESP32、无局域网时也可演示完整流程。
- 新增 LD2450 最近目标二维位置图和左/中/右区域显示。
- 新增空气评分、温度、湿度三条历史趋势曲线。
- 新增可配置自动化规则，阈值和动作档位持久化到 NVS。
- 新增回家、离家、睡眠、通风、强力净化五种场景。
- 新增最近 32 条事件环形日志，覆盖设备、模式、环境、雷达、告警、场景和自动化。
- 新增 `GET /api/events`、`POST /api/automation`、`POST /api/scene`。
- PowerShell API 检查脚本新增 `/api/events` 验证。
- 回归测试改为检查仓库根目录的正式小程序工程，避免误用历史副本。

## 自动化规则语义

自定义规则只在自动模式下执行：

- 空气评分低于阈值：净化器和新风至少提升到配置档位。
- 湿度低于阈值：加湿器至少提升到配置档位。
- 温度高于阈值：新风至少提升到配置档位。

设备处于手动覆盖期时，规则不会覆盖该设备。规则配置保存在 `smart_home` NVS 命名空间中。

## 边界

- 事件日志和环境历史保存在 RAM，设备重启后清空，避免高频写 Flash。
- 离线模式是小程序本地模拟，不代表真实硬件状态。
- 雷达图当前显示最近目标，不绘制全部三个目标。
- 趋势曲线采用最近 30 个采样点，不是长期数据库。
