# 2026-07-08 答辩 PPT 优化版阶段交付

## 本阶段目标

在已生成的重做版材料基础上，继续优化答辩 PPT，使其更适合明早现场答辩使用。优化重点：

- PPT 样式精美但不过于花哨。
- 主色控制在深墨绿、浅灰白、暖橙三种以内。
- 减少大段文字，每页只讲一个重点。
- 语言更像真人答辩表达，避免空泛和 AI 味。
- 配图形式多样，包含实物照片、屏幕截图、流程图、状态链路和完成情况页。

## PPT 页面结构

1. 标题页：展示作品实物和系统定位。
2. 问题页：说明室内环境管理的痛点。
3. 系统主线：说明所有入口共用同一份状态。
4. 串口屏：展示现场查看和触摸控制。
5. 小程序：展示手机端状态读取和档位控制。
6. AI 语音：说明语音到 MCP 工具再到 HTTP API 的链路。
7. 自动与节能：说明规则和执行动作。
8. 完成情况：列出各链路可观察结果。
9. 应用价值：面向家庭、宿舍、教室、小办公室等场景。

## 使用建议

明早答辩建议使用优化版 PPT：

`docs/report_output_rebuild/final/喵伴空气管家答辩PPT_优化版_2026-07-08.pptx`

建议讲述顺序与 PPT 保持一致：

1. 先讲为什么做。
2. 再讲系统怎样把传感器、屏幕、小程序、AI 和执行器连起来。
3. 接着展示串口屏、小程序、AI 语音和自动模式。
4. 最后落到应用场景和后续扩展。

## 遗留事项

- PPT 中没有填写队伍、编号、作者等身份信息，如需要可由用户手动补到标题页或封面页。
- 小程序截图目前主要来自硬件实拍中的手机画面；若后续有更清晰的小程序单独截图，可替换第 5 页左侧图片。
- 若答辩现场时间非常紧，可以只讲第 1、3、4、5、6、7、9 页，第 2 和第 8 页快速带过。
